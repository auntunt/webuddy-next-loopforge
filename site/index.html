Self-Healing Flywheel

五步诊断自愈引擎：先硬后软，宁可不修也不误修

针对单周 UI 迭代导致传统脚本大面积失效的顽疾，建立严格置信度门禁与跨页防误修防火墙。

1

目标服务探活

先检 502 / 断连 / 超时，判定为环境故障立即停止，绝不误改测试脚本。

2

驱动会话存活

校验 Headless Chrome CDP 会话与页面 DOM 状态，排除驱动异常。

3

视觉与语义弹窗

自动识别权限/合规弹窗放行、引导/通知弹窗关闭，并原地重试原定位器。

4

跨页语义防火墙

校验路由基线（如 /admin.html），若掉登录跳回 /login 直接拦截，严防跨页假成功。

5

三维画像 ≥ 0.80

语义角色 + 业务父上下文 + DOM 层级三维打分达标才原地重试、生成快照与判例；否则一键转缺陷单。
