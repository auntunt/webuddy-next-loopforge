# TMH 代码图谱、14K 全量代码审查与多租户团队协作指南

---

## 1. TMH 多语言代码图谱（`webuddy_core`）

传统 Coding Agent 在接手存量业务代码时，往往靠零散 `grep` 盲人摸象。Webuddy 内置零外部依赖的 **TMH 代码图谱引擎**，支持 Go / Python / TypeScript / JavaScript / Node HTTP / NestJS / Next.js / Rust / Java / C# / PHP / SQL 等多语言仓库：

- **四层结构化抽离**：自动抽取 **业务域（Domains） → 核心业务流程（Flows） → 数据表（Tables） → 确定性状态机（Statecharts）**；
- **`file:line` 源码行级溯源核验**：每条知识页与证据链均绑定真实源码文件路径、行号与 Git Commit Hash，杜绝文档漂移与 AI 幻觉；
- **增量智能更新**：SOP 交付成功合并后自动触发增量图谱刷新，也可在对话中由 Main Bot 调用 `webuddy_kb_update` 批量补齐未分析页面。

## 2. 14K 分批全量 AI 代码审查

面对跨模块的大体积改动，单次 Prompt 往往因上下文截断而漏审关键缺陷。Webuddy 代码审查工作台提供：

1. **14K 字符智能分批审查**：按文件边界与改动上下文自动切分大型 Diff，逐批深度审查；
2. **分级门禁（Blocker / Advisory）**：将阻断级安全/逻辑漏洞与建议级风格优化清晰分层，阻断项未解除前自动拦住验收关口；
3. **人工有效性反馈闭环**：研发人员可对每条 AI 审查意见标记“有效 / 误报 / 已采纳”，持续校准团队审查标准；
4. **控制面安全交付 PR**：即使执行沙箱或内网 WSL2 机器没有外网访问权限，控制面也能基于 `repository-patch` 自动推送分支并创建真实 GitHub PR / GitLab MR。

## 3. 企业多租户隔离与多容器协同开发

### 3.1 多租户空间治理
- 支持创建多个独立团队空间（Tenant），通过 **邀请码** 准入并按成员角色（Admin / Member / Viewer）细粒度鉴权；
- 项目列表、代码知识库、团队共享知识中心、会话记录、自动化测试资产与效能统计均严格按租户隔离。

### 3.2 团队知识自动沉淀（零人工录入）
- 每次 SOP 交付完成后，系统自动采集 `knowledge.md` / `lessons-encoded.md` 产物并去重入库至 **租户共享知识中心**；
- 在隔离多容器协同开发（如后端算薪开发、外部同步开发、QA 审计与知识库整理分容器并行）场景下，各成员与 Agent 均可通过 `webuddy_kb_shared_search` 实时检索团队历史架构决策与踩坑指南，消除协同“暗物质”。
